# Production — La Ferme Patapouf

La méthode de fabrication est la même que pour la série refuge. Les deux options (images IA cohérentes ou scène 3D),
la voix off, les sous-titres et le montage sont décrits dans [`../serie-refuge/production.md`](../serie-refuge/production.md).
Ici, uniquement ce qui est propre à la ferme.

**Style à coller à la fin de chaque prompt :**
```
stylized 3D cartoon render, toy-like low-poly look, soft rounded shapes, characters with big round
white eyes and tiny pupils, rainy evening, muted blue-grey and green palette with warm yellow and
red accents, soft volumetric light, vertical 9:16, clean composition, no text
```

## Le décor
**La ferme (jour 1) :**
```
an abandoned countryside farm in the rain: an old wooden barn with a leaking roof, a broken wooden
fence enclosure, a single hay bale, an old red tractor, muddy ground with puddles, a hand-painted
wooden gate sign, empty and a bit sad but cute, wide shot, [style]
```
**La grange vide (plan du compteur à 0) :**
```
inside an empty old wooden barn, straw on the floor, rain dripping through holes in the roof,
small empty wooden puppy boxes with question marks, [style]
```
**La grange qui déborde (plan du compteur, jours 2 et suivants) :**
```
the same old wooden barn, its doors bursting open, hundreds of tiny cute puppies of all breeds
pouring out, puppies on the roof, in the hay, everywhere, funny chaotic scene, [style]
```
**Des chiots partout :**
```
an old red tractor completely filled with tiny puppies of different breeds, puppies on the seat and
the wheels, [style]
```
```
an old sleeping basset hound with a white muzzle completely covered with dozens of tiny puppies,
still asleep, [style]
```

## Les personnages
**Le fondateur :**
```
a friendly cartoon man in a bright yellow raincoat, rubber boots and a white construction helmet,
holding rolled-up building plans, standing on a muddy farm, full body, [style]
```
**Papi Gaston** : reprends le prompt de la série refuge, en ajoutant `sleeping on a hay bale`.
**Brioche :**
```
a very round chubby pug with its head inside a torn bag of dog kibble, kibble everywhere, [style]
```
**Choupette :**
```
a tiny chihuahua wearing a yellow construction helmet, standing on the hood of an old red tractor,
giving orders with a fierce face, a small excavator in the background, [style]
```
**Roger le tracteur :**
```
an old rusty red farm tractor with a funny face-like front, black smoke coming out of the exhaust,
[style]
```

## L'adoption (la scène clé de chaque épisode)
```
a small cartoon person in a hoodie walking away through the farm gate, happily carrying a
[golden retriever / husky / french bulldog…] puppy in their arms, other puppies watching, sunset
after the rain, heartwarming, [style]
```
➡️ Dans CapCut, ajoute au-dessus du personnage une **étiquette avec le pseudo** (@pseudo), puis un
**certificat d'adoption** : une carte crème avec le titre « CERTIFICAT D'ADOPTION n° 00X », la race, le nom du chiot,
le pseudo et un tampon « FERME PATAPOUF ».

## Les constructions (une image par vote gagné)
```
the same farm, a small yellow excavator building [a heated puppy nursery / a big fenced green
enclosure / a puppy swimming pool / a giant warehouse with a "Patapouf" sign], a tiny chihuahua in a
helmet supervising, [style]
```

## La rivale
```
a pink luxurious mini-castle next to a farm field, an elegant snobbish lady with a tall hairdo and
perfectly groomed white poodles, looking annoyed at hundreds of muddy puppies running in her garden,
[style]
```

## La Cagnotte
```
a giant shiny metal dog bowl on a wooden bench in a barn, overflowing with gold coins and banknotes,
[style]
```

## Les graphismes à créer une fois
Les mêmes que pour la série refuge (badge JOUR X, compteur, cartes A/B/C, badge DÉCISION N° X), plus :
- l'étiquette **« 1 ABONNÉ = 1 CHIOT »** ;
- le badge **« CHIOT OG · Adoption n° 001 »** ;
- le **certificat d'adoption** (modèle à dupliquer) ;
- le badge **« 🏆 TOP COMMENTAIRE · X ❤️ »** à poser sur la capture du commentaire ;
- le **tableau de classement des adoptants** (dès le jour 4).
